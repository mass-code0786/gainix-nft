# Gainix NFT Prompt Pack

## Global Style Anchor
Use this anchor at the start of every concept or trait prompt:

```text
Use case: stylized-concept
Asset type: premium NFT collection asset
Primary request: create a luxury Web3 character asset for Gainix NFT
Style/medium: high-polish stylized 3D illustration with collector-grade finish
Composition/framing: centered square portrait, fixed premium rig, consistent head scale
Lighting/mood: black studio lighting, deep crimson rim light, subtle metallic speculars
Color palette: obsidian black, graphite, ruby red, antique gold, smoked silver
Materials/textures: velvet fur or feathers, brushed metal, smoked glass, carbon weave
Constraints: premium dark luxury only; consistent style across the full collection; no cartoon comedy; no text; no watermark
Avoid: pastel colors, childlike proportions, goofy expressions, chaotic backgrounds, low-detail rendering
```

## Consistency Notes For Every Prompt
- Keep the same camera angle and portrait crop.
- Treat red as an accent, not a full-scene wash.
- Keep accessory scale realistic and premium.
- Preserve clean, production-grade PNG edges for all layers.
